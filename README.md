# fullstack_developer_capstone

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Names
fullstack_developer_capstone

## Project Description
This project is a full-stack car dealership application
developed using Django, React, and MongoDB.

It allows users to view car dealerships, explore dealer
details, register and log in, submit reviews, and analyze
customer review sentiment.

## Technologies Used
- Python
- Django
- React
- JavaScript
- MongoDB
- Docker
- Kubernetes
- GitHub Actions
